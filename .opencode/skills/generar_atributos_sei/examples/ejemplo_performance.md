# Ejemplo — Rendimiento

## Situación

Una aplicación web permite a los usuarios realizar búsquedas de películas. El sistema debe responder en menos de 2 segundos  ante una consulta.

## Atributo de calidad

Rendimiento (Performance)

## Escenario SEI

| Fuente del estímulo | Estímulo | Entorno | Artefacto | Respuesta | Medida de respuesta |
|---|---|---|---|---|---|
| Usuario | Realiza una búsqueda de una película | Operación normal | Sistema de búsqueda | Procesa la consulta y devuelve los resultados | Las consultas se deben responder en menos de 2 segundos |

## Por qué es un buen escenario

- La fuente del estímulo está identificada.
- El estímulo es un evento concreto.
- El entorno indica cuándo ocurre.
- El artefacto identifica la parte del sistema involucrada.
- La respuesta indica qué hace el sistema.
- La medida es cuantificable.
