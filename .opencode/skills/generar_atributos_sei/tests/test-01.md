# Test 01

## Objetivo

Verificar que la skill pueda identificar y generar correctamente un escenario SEI a partir de un requisito completo.

## Entrada

El sistema debe responder las consultas de los usuarios en menos de 2 segundos durante condiciones normales de operación.

## Resultado esperado

La skill debe identificar correctamente el atributo de calidad correspondiente y generar un escenario utilizando las seis partes del template SEI.

## Criterios de aprobación

- Identifica correctamente el atributo de calidad.
- Las seis partes están presentes.
- La medida de respuesta es cuantificable.
- No agrega supuestos innecesarios.
- Existe coherencia entre estímulo y respuesta.
