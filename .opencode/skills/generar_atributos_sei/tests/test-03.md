# Test 03

## Objetivo

Verificar que la skill solicite información cuando no puede determinar el atributo de calidad.

## Entrada

Quiero crear un escenario de calidad para mi sistema de gestión de películas.

## Resultado esperado

La skill debe detectar que falta información fundamental y solicitar al usuario que indique qué atributo de calidad desea evaluar.

## Criterios de aprobación

- Detecta que falta el atributo de calidad.
- No selecciona uno arbitrariamente.
- No genera un escenario todavía.
- Solicita únicamente la información necesaria para continuar.
